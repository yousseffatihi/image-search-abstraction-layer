Image Search Abstraction Layer

A freeCodeCamp API project. Images come from Wikimedia Commons.

API usage

  • Search images: GET /query/<search string>?page=<n>
    Example: /query/lolcats funny?page=2
  • Recent searches: GET /recent
    Example: /recent

Each result contains url, snippet, thumbnail and context (the page the image is from).
